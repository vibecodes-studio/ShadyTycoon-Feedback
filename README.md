# Shady Tycoon – Feedback

Bug reports and wishes from Shady Tycoon testers. The game's source code is not in this repository.

## Report something

1. Open **[Issues → New issue](../../issues/new/choose)**.
2. Choose **Bug report** or **Wish / idea**.
3. Fill in the form. Screenshots help a lot: drag them straight into the text box.

The game version is shown at the bottom left of the title screen (e.g. `0.1.210`).

## Board

All reports are on the [project board](https://github.com/orgs/vibecodes-studio/projects/1), sorted by status:

**New → Confirmed → In progress → Fixed (next update) → Done**

"Fixed (next update)" means the fix is built but not released yet. When an update with the fix comes out, the report is closed and the comment names the version.

## Discord

You can still post in the Discord tester forum. Posts from there are copied here so everything is in one place.
